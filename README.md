# PsyShop

Proyecto de comercio electrónico para videojuegos de consola.

## Tecnologías Utilizadas
* **Backend:** PHP, Laravel, MySQL, Laravel Sanctum (Autenticación).
* **Frontend Web:** Vue 3.
* **Frontend Móvil:** Ionic Framework.

## Descripción del Proyecto
Plataforma e-commerce que incluye vista de catálogo, carrito de compras, gestión de usuarios, panel de administración para control de stock e integración de correos automatizados de confirmación de órdenes.
